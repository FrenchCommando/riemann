A field with 256 elements

Évariste Galois, "Sur la théorie des nombres", 1830; the byte field of QR codes, ISO/IEC 18004
Theorem

If fff is an irreducible polynomial of degree nnn with coefficients in Fp=Z/p\mathbb F_p = \mathbb Z/pFp​=Z/p, then the polynomials taken mod fff form a field with pnp^npn elements. With p=2p = 2p=2 and f=x8+x4+x3+x2+1f = x^8 + x^4 + x^3 + x^2 + 1f=x8+x4+x3+x2+1, its elements are bytes: this is the field QR codes compute in.

Galois's other invention. Arithmetic on bytes mod 256 is no good for error correction because you can't divide: 2⋅128=02 \cdot 128 = 02⋅128=0. This proof builds a different arithmetic on 8-bit strings where every nonzero byte can be divided by. The recipe is the one that builds Z/p\mathbb Z/pZ/p from the integers, with primes replaced by irreducible polynomials.

Proof · 5 steps
  1. 1Remainders mod f

    Every polynomial over Fp\mathbb F_pFp​ leaves a remainder of degree <n\lt n<n on division by fff, and there are exactly pnp^npn possible remainders.

    Division with remainder gives g=qf+rg = qf + rg=qf+r with deg⁡r<n\deg r \lt ndegr<n. A remainder is a0+a1x+⋯+an−1xn−1a_0 + a_1 x + \dots + a_{n-1} x^{n-1}a0​+a1​x+⋯+an−1​xn−1, with ppp choices for each of the nnn coefficients.

    More detail

    This is the same move as Z/p\mathbb Z/pZ/p: every integer leaves one of ppp remainders, and we compute with remainders only.

    With p=2p = 2p=2 and n=8n = 8n=8 a remainder is a list of 888 bits: a byte, with bit iii the coefficient of xix^ixi. For example the byte 0x53=01010011\mathtt{0x53} = 010100110x53=01010011 is x6+x4+x+1x^6 + x^4 + x + 1x6+x4+x+1.

  2. 2Arithmetic mod f

    Add or multiply two remainders as polynomials, then reduce mod fff. This is well defined and obeys the usual rules of arithmetic.

    It works exactly as congruences mod nnn do: if g≡g′g \equiv g'g≡g′ and h≡h′(modf)h \equiv h' \pmod fh≡h′(modf), then fff divides g+h−(g′+h′)g + h - (g' + h')g+h−(g′+h′) and gh−g′h′=g(h−h′)+(g−g′)h′gh - g'h' = g(h - h') + (g - g')h'gh−g′h′=g(h−h′)+(g−g′)h′. The usual rules hold for polynomials, so they hold for remainders.

    More detail

    Over F2\mathbb F_2F2​, coefficients add mod 222, so adding two bytes is bitwise XOR, and every element is its own negative: a+a=0a + a = 0a+a=0.

    Multiplying uses f=0f = 0f=0 as a rewriting rule. In the four-element field, f=x2+x+1f = x^2 + x + 1f=x2+x+1 gives x2=−x−1=x+1x^2 = -x - 1 = x + 1x2=−x−1=x+1 (signs don't matter mod 222). So x⋅(x+1)=x2+x=(x+1)+x=1.x \cdot (x + 1) = x^2 + x = (x + 1) + x = 1.x⋅(x+1)=x2+x=(x+1)+x=1.

  3. 3Irreducible means you can divide

    If fff is irreducible, every nonzero remainder ggg has an inverse mod fff. If fff factors, some nonzero elements have none.

    Irreducible means the only divisors of fff are constants and constant multiples of fff; since f∤gf \nmid gf∤g, gcd⁡(g,f)=1\gcd(g, f) = 1gcd(g,f)=1. Euclid's algorithm for polynomials then gives Bézout: ag+bf=1ag + bf = 1ag+bf=1, so ag≡1(modf)ag \equiv 1 \pmod fag≡1(modf).

    More detail

    Euclid's algorithm works for polynomials for the same reason as for integers: each division strictly lowers the degree, so it stops, and running it backwards writes the last nonzero remainder, the gcd, as ag+bfag + bfag+bf. (This is Bézout's identity from the Fundamental Theorem of Arithmetic, with degree in place of size.)

    If instead f=ghf = ghf=gh with g,hg, hg,h of smaller degree, then g⋅h≡0g \cdot h \equiv 0g⋅h≡0 while neither is 000. An inverse of ggg would give h=g−1gh≡0h = g^{-1} g h \equiv 0h=g−1gh≡0, a contradiction. That is the polynomial version of 2⋅3=02 \cdot 3 = 02⋅3=0 in Z/6\mathbb Z/6Z/6.

  4. 4The field of bytes

    f=x8+x4+x3+x2+1f = x^8 + x^4 + x^3 + x^2 + 1f=x8+x4+x3+x2+1 is irreducible over F2\mathbb F_2F2​. So bytes, with XOR for addition and multiplication mod fff, form a field F256\mathbb F_{256}F256​.

    If fff factored, one factor would have degree ≤4\le 4≤4, and it could be taken irreducible. There are only 888 irreducible polynomials of degree ≤4\le 4≤4 over F2\mathbb F_2F2​, and dividing fff by each leaves a nonzero remainder.

    More detail

    The eight candidates are xxx, x+1x + 1x+1, x2+x+1x^2 + x + 1x2+x+1, x3+x+1x^3 + x + 1x3+x+1, x3+x2+1x^3 + x^2 + 1x3+x2+1, x4+x+1x^4 + x + 1x4+x+1, x4+x3+1x^4 + x^3 + 1x4+x3+1 and x4+x3+x2+x+1x^4 + x^3 + x^2 + x + 1x4+x3+x2+x+1. Two are quick by hand: f(0)=1f(0) = 1f(0)=1, so xxx is not a factor, and f(1)=1+1+1+1+1=1f(1) = 1 + 1 + 1 + 1 + 1 = 1f(1)=1+1+1+1+1=1, so x+1x + 1x+1 is not either. The other six take a few lines of long division each (or a computer, in microseconds).

    The QR standard fixes this fff, written as the number 285=28+24+23+22+1285 = 2^8 + 2^4 + 2^3 + 2^2 + 1285=28+24+23+22+1. A sample product: 0x02⋅0x80=x⋅x7=x8\mathtt{0x02} \cdot \mathtt{0x80} = x \cdot x^7 = x^80x02⋅0x80=x⋅x7=x8, and f=0f = 0f=0 means x8=x4+x3+x2+1x^8 = x^4 + x^3 + x^2 + 1x8=x4+x3+x2+1, which is the byte 0x1D\mathtt{0x1D}0x1D.

  5. 5Conclude

    So Fp[x]/(f)\mathbb F_p[x]/(f)Fp​[x]/(f) is a field with pnp^npn elements, and F256\mathbb F_{256}F256​ is one. ■\blacksquare■

    Step 2 gives the rules of arithmetic, step 3 gives inverses of nonzero elements, and step 1 counts the elements.

    More detail

    Two facts the rest of the path doesn't need, stated without proof: the number of elements of a finite field is always a prime power (there is no field with 666 or 101010 elements), and any two finite fields of the same size are the same up to renaming (Moore, 1893). So "the" field with 256256256 elements makes sense, and choosing a different irreducible fff only relabels the bytes.

Takeaway. Replace integers by polynomials and primes by irreducible polynomials, and the construction of Z/p\mathbb Z/pZ/p builds a field of size pnp^npn, including one whose elements are bytes.
