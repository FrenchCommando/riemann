Cantor's theorem: no set is as big as its power set

Georg Cantor, 1891
Theorem

For every set SSS, there is no surjection f:S→P(S)f : S \to \mathcal P(S)f:S→P(S). Hence ∣P(S)∣>∣S∣|\mathcal P(S)| \gt |S|∣P(S)∣>∣S∣.

The diagonal argument, stripped to its essence — no decimals, no lists, five lines. It shows there is no largest infinity.

Builds on The real numbers are uncountable.

Proof · 5 steps
  1. 1Assume a surjection

    Suppose f:S→P(S)f : S \to \mathcal P(S)f:S→P(S) is onto: every subset of SSS equals f(x)f(x)f(x) for some xxx.

    Proof by contradiction. We'll build a subset of SSS that fff misses.

    More detail

    fff assigns to each element x∈Sx \in Sx∈S a subset f(x)⊆Sf(x) \subseteq Sf(x)⊆S. "Onto" means every subset is hit. If we can name one subset that is not f(x)f(x)f(x) for any xxx, we're done.

  2. 2The diagonal set

    Let D={x∈S:x∉f(x)}D = \{x \in S : x \notin f(x)\}D={x∈S:x∈/f(x)}.

    DDD collects the elements that are not members of their own image. It is a perfectly good subset of SSS.

    More detail

    For each xxx ask one yes/no question: is xxx in the set f(x)f(x)f(x)? Put xxx into DDD exactly when the answer is no.

    This is the diagonal again: think of a table with rows xxx and columns yyy, entry "is y∈f(x)y \in f(x)y∈f(x)?". DDD is the row obtained by flipping every diagonal entry.

  3. 3D must be hit

    Since fff is onto, D=f(d)D = f(d)D=f(d) for some d∈Sd \in Sd∈S.

    DDD is a subset of SSS, and we assumed every subset is in the image.

    More detail

    This is the only place surjectivity is used. Now ask the diagonal question about ddd itself.

  4. 4Is d in D?

    d∈D  ⟺  d∉f(d)  ⟺  d∉Dd \in D \iff d \notin f(d) \iff d \notin Dd∈D⟺d∈/f(d)⟺d∈/D. Contradiction.

    The first equivalence is the definition of DDD; the second uses f(d)=Df(d) = Df(d)=D. A statement equivalent to its own negation is impossible.

    More detail

    Two cases:

    • If d∈Dd \in Dd∈D, then by definition of DDD, d∉f(d)=Dd \notin f(d) = Dd∈/f(d)=D. Contradiction.
    • If d∉Dd \notin Dd∈/D, then d∉f(d)d \notin f(d)d∈/f(d), so ddd meets the condition for DDD: d∈Dd \in Dd∈D. Contradiction.

    Either way we're stuck, so no such ddd exists, and fff is not onto. ■\blacksquare■

  5. 5Strictly bigger

    ∣S∣<∣P(S)∣|S| \lt |\mathcal P(S)|∣S∣<∣P(S)∣, so ∣N∣<∣P(N)∣<∣P(P(N))∣<⋯|\mathbb N| \lt |\mathcal P(\mathbb N)| \lt |\mathcal P(\mathcal P(\mathbb N))| \lt \cdots∣N∣<∣P(N)∣<∣P(P(N))∣<⋯

    x↦{x}x \mapsto \{x\}x↦{x} is an injection S→P(S)S \to \mathcal P(S)S→P(S), so P(S)\mathcal P(S)P(S) is at least as big; Cantor's theorem rules out equality.

    More detail

    Iterating gives an endless tower of infinite sizes. P(N)\mathcal P(\mathbb N)P(N) has the same size as R\mathbb RR (a subset of N\mathbb NN is a 0/1 sequence, i.e. a binary expansion), which recovers the previous theorem.

    Apply the argument to "the set of all sets" and you get Russell's paradox: D={x:x∉x}D = \{x : x \notin x\}D={x:x∈/x}. That's why modern set theory forbids such a set.

Takeaway. Diagonalisation in one line: D={x:x∉f(x)}D = \{x : x \notin f(x)\}D={x:x∈/f(x)} disagrees with every f(x)f(x)f(x) about xxx.
