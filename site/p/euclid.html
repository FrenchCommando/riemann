There are infinitely many primes

Euclid, Elements IX.20, c. 300 BC
Theorem

For every finite list of primes, there is a prime not on it.

Perhaps the most famous proof in mathematics. It is short, but one step is widely misremembered — watch for it.

Walk through it step by step a check at each step, detail adjusted to what you know
Proof · 5 steps
  1. 1Suppose the list is complete

    Assume there are only finitely many primes, p1,p2,…,pnp_1, p_2, \dots, p_np1​,p2​,…,pn​.

    Proof by contradiction: assume the opposite of the claim. The payoff is that we now hold a concrete list we can compute with.

    More detail

    The negation of "infinitely many primes" is "finitely many", and a finite set can be listed. There is at least one prime (2), so n≥1n \ge 1n≥1.

  2. 2Build a new number

    Let N=p1p2⋯pn+1N = p_1 p_2 \cdots p_n + 1N=p1​p2​⋯pn​+1.

    NNN is designed so that dividing it by any pip_ipi​ leaves remainder 1.

    More detail

    Multiply every prime on the list together, then add 1. For example, if the list were 2,3,52, 3, 52,3,5, we'd get N=31N = 31N=31.

    The "+1" is the whole trick: p1⋯pnp_1 \cdots p_np1​⋯pn​ is divisible by every pip_ipi​, so NNN is "one more than a multiple" of each.

  3. 3N has a prime divisor

    N>1N \gt 1N>1, so NNN has some prime divisor qqq.

    Every integer greater than 1 has at least one prime divisor (its smallest divisor above 1 is prime).

    More detail

    N≥2+1=3N \ge 2 + 1 = 3N≥2+1=3. Take the smallest d>1d \gt 1d>1 with d∣Nd \mid Nd∣N; if ddd weren't prime, a smaller divisor of ddd would also divide NNN. So q=dq = dq=d is prime.

    Note: qqq might be NNN itself, or it might be smaller. We don't need to know which.

  4. 4q is not on the list

    If q=piq = p_iq=pi​ for some iii, then q∣1q \mid 1q∣1 — impossible.

    pip_ipi​ divides both NNN and p1⋯pnp_1\cdots p_np1​⋯pn​, so it divides their difference, which is 1.

    More detail

    Suppose q=piq = p_iq=pi​. Then:

    • q∣Nq \mid Nq∣N (by choice of qqq),
    • q∣p1p2⋯pnq \mid p_1 p_2 \cdots p_nq∣p1​p2​⋯pn​ (it's one of the factors).

    A number dividing two integers divides their difference: q∣N−p1⋯pn=1q \mid N - p_1\cdots p_n = 1q∣N−p1​⋯pn​=1. But a prime is at least 2 and can't divide 1.

  5. 5Conclude

    qqq is a prime not in the list — contradiction. So there are infinitely many primes.

    The list was supposed to contain every prime.

    More detail

    Read constructively, the proof is an algorithm: given any finite set of primes, the prime factors of (product + 1) are new primes. It never runs out.

    Later in this course, Euler's proof gives a much stronger statement: the primes are dense enough that ∑1/p\sum 1/p∑1/p diverges.

Takeaway. Construct an object (product + 1) that every candidate fails to divide.
