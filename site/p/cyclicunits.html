On the way to Galois theory: no formula for the quintic

Every finite field has a primitive element

Gauss, Disquisitiones Arithmeticae, 1801 (for Z/p); Galois, 1830
Theorem

In a field with qqq elements, some element α\alphaα has order q−1q - 1q−1: the nonzero elements are exactly 1,α,α2,…,αq−21, \alpha, \alpha^2, \dots, \alpha^{q-2}1,α,α2,…,αq−2.

Multiplying bytes by "multiply, then reduce mod fff" is slow. QR encoders instead write every nonzero byte as a power of one fixed byte and add exponents, the way slide rules add logarithms. This proof shows such an element always exists, by counting.

Builds on Lagrange's theorem, A field with 256 elements.

Proof · 5 steps
  1. 1Orders divide q − 1

    The nonzero elements form a group of size q−1q - 1q−1 under multiplication, so the order of every nonzero element divides q−1q - 1q−1.

    Products of nonzero elements are nonzero (no zero divisors), and every nonzero element has an inverse. By Lagrange, the order of aaa, the size of the subgroup {1,a,a2,… }\{1, a, a^2, \dots\}{1,a,a2,…}, divides the size of the group.

    More detail

    So aq−1=1a^{q-1} = 1aq−1=1 for every a≠0a \ne 0a=0, which is Fermat's Little Theorem when the field is Fp\mathbb F_pFp​. The question is whether some element has order exactly q−1q - 1q−1, rather than a proper divisor of it.

  2. 2Few elements of each order

    For each ddd dividing q−1q - 1q−1, at most φ(d)\varphi(d)φ(d) elements have order exactly ddd.

    If some aaa has order ddd, then 1,a,…,ad−11, a, \dots, a^{d-1}1,a,…,ad−1 are ddd different roots of xd−1x^d - 1xd−1. That polynomial has at most ddd roots, so these are all of them, and every element of order ddd is some aka^kak.   5. 5Logarithm tables in QR encoders

    In F256\mathbb F_{256}F256​ built from x8+x4+x3+x2+1x^8 + x^4 + x^3 + x^2 + 1x8+x4+x3+x2+1, the byte α=x\alpha = xα=x (that is, 0x02\mathtt{0x02}0x02) is primitive. So ab=α(log⁡a+log⁡b) mod 255ab = \alpha^{(\log a + \log b) \bmod 255}ab=α(loga+logb)mod255.

    The order of α\alphaα divides 255=3⋅5⋅17255 = 3 \cdot 5 \cdot 17255=3⋅5⋅17. It is 255255255 unless α255/3\alpha^{255/3}α255/3, α255/5\alpha^{255/5}α255/5 or α255/17\alpha^{255/17}α255/17 equals 111, and computing α85\alpha^{85}α85, α51\alpha^{51}α51 and α15\alpha^{15}α15 shows none does.

    More detail

    The test works because any proper divisor of 255255255 divides 858585, 515151 or 151515. A polynomial whose root xxx is primitive is called a primitive polynomial; the QR standard chose one, so the encoder can start from 111 and keep multiplying by 222 (shift left, XOR with 0x11D\mathtt{0x11D}0x11D on overflow) to list all 255255255 powers.

    It stores two tables: exp⁡[i]=αi\exp[i] = \alpha^iexp[i]=αi and its inverse log⁡\loglog. Then multiplication is two lookups, an addition mod 255255255, and a lookup. The QR code on the Reed–Solomon page of this site is computed exactly this way.

Takeaway. Counting alone forces a generator: each order ddd has room for at most φ(d)\varphi(d)φ(d) elements, and those maxima add up to exactly q−1q - 1q−1.
