The real numbers are uncountable

Georg Cantor, diagonal argument, 1891
Theorem

There is no list r1,r2,r3,…r_1, r_2, r_3, \dotsr1​,r2​,r3​,… containing every real number.

Some infinities are bigger than others. The diagonal trick in this proof reappears in Gödel's incompleteness theorem and Turing's halting problem.

Proof · 6 steps
  1. 1Reduce to (0, 1)

    It suffices to show the interval (0,1)(0, 1)(0,1) is uncountable.

    A list of all reals would contain all of (0,1)(0,1)(0,1); deleting the others would give a list of (0,1)(0,1)(0,1).

    More detail

    If R\mathbb{R}R could be listed as r1,r2,…r_1, r_2, \dotsr1​,r2​,…, go through the list and keep only the entries in (0,1)(0,1)(0,1). That's still a sequence, now listing every element of (0,1)(0,1)(0,1). So "(0,1)(0,1)(0,1) uncountable" implies "R\mathbb{R}R uncountable".

  2. 2Assume a complete list

    Suppose r1,r2,r3,…r_1, r_2, r_3, \dotsr1​,r2​,r3​,… lists every number in (0,1)(0, 1)(0,1).

    Proof by contradiction: we'll build a number in (0,1)(0,1)(0,1) that the list misses.

    More detail

    Uncountable means "every list misses something". So we take an arbitrary list and show it misses something — equivalently, assume a complete list exists and reach a contradiction.

  3. 3Write out the digits

    Write rn=0.dn1 dn2 dn3…r_n = 0.d_{n1}\, d_{n2}\, d_{n3} \dotsrn​=0.dn1​dn2​dn3​… in decimal.

    Arrange the list as an infinite grid: row nnn holds the digits of rnr_nrn​.

    More detail

    r1=0. d11 d12 d13…r2=0. d21 d22 d23…r3=0. d31 d32 d33…\begin{array}{l} r_1 = 0.\,\mathbf{d_{11}}\, d_{12}\, d_{13} \dots \\ r_2 = 0.\,d_{21}\, \mathbf{d_{22}}\, d_{23} \dots \\ r_3 = 0.\,d_{31}\, d_{32}\, \mathbf{d_{33}} \dots \end{array}r1​=0.d11​d12​d13​…r2​=0.d21​d22​d23​…r3​=0.d31​d32​d33​…​ The bold digits form the diagonal. (Some numbers have two expansions, like 0.5=0.4999…0.5 = 0.4999\ldots0.5=0.4999…; pick either — the next step is designed so it doesn't matter.)

  4. 4Change every diagonal digit

    Define x=0.e1e2e3…x = 0.e_1 e_2 e_3 \dotsx=0.e1​e2​e3​… where en=5e_n = 5en​=5 if dnn≠5d_{nn} \ne 5dnn​=5, and en=4e_n = 4en​=4 if dnn=5d_{nn} = 5dnn​=5.

    xxx differs from rnr_nrn​ in the nnn-th digit, for every nnn.

    More detail

    Go down the diagonal and change each digit. The specific rule (use 4 and 5) only matters for the next step; any rule that always changes the digit and never uses 0 or 9 works.

    xxx is between 0.444…0.444\ldots0.444… and 0.555…0.555\ldots0.555…, so certainly x∈(0,1)x \in (0,1)x∈(0,1).

  5. 5x is not on the list

    x≠rnx \ne r_nx=rn​ for every nnn.

    xxx's nnn-th digit differs from rnr_nrn​'s nnn-th digit, and xxx has a unique expansion.

    More detail

    Suppose x=rnx = r_nx=rn​ for some nnn. xxx has only one decimal expansion (no 0s or 9s), so rnr_nrn​'s expansion — whichever one we wrote — must be that one, digit for digit. But their nnn-th digits are en≠dnne_n \ne d_{nn}en​=dnn​. Contradiction.

    Note this is for a fixed but arbitrary nnn, so it holds for all nnn.

  6. 6Conclude

    The list misses x∈(0,1)x \in (0,1)x∈(0,1), contradicting completeness. So (0,1)(0,1)(0,1), and hence R\mathbb{R}R, is uncountable.

    We assumed the list was complete and found an element not on it.

    More detail

    Why doesn't this prove Q\mathbb{Q}Q is uncountable? Run the argument on a list of rationals: you get an xxx missing from the list, but nothing forces xxx to be rational — so no contradiction. The proof works for R\mathbb{R}R because every digit sequence is a real number.

Takeaway. Diagonalisation: given any list, build an object that disagrees with the nnn-th entry in the nnn-th place.

Used by Cantor's theorem: no set is as big as its power set.
