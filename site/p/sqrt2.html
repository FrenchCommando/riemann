2\sqrt22​ is irrational

Pythagorean school, c. 5th century BC
Theorem

There are no integers p,qp, qp,q with q≠0q \ne 0q=0 such that (pq)2=2\left(\frac pq\right)^2 = 2(qp​)2=2.

The first proof that some lengths can't be expressed as ratios of whole numbers. The pattern — assume a fraction in lowest terms, then show both parts share a factor — reappears all over number theory.

Proof · 5 steps
  1. 1Assume the opposite, in lowest terms

    Suppose 2=pq\sqrt2 = \frac pq2​=qp​ with integers p,qp, qp,q, q≠0q \ne 0q=0, and gcd⁡(p,q)=1\gcd(p,q) = 1gcd(p,q)=1.

    This is a proof by contradiction, so we assume 2\sqrt 22​ is rational. Any fraction can be reduced to lowest terms, so we may also assume ppp and qqq share no common factor.

    More detail

    "Rational" means "equal to some fraction". If 2=ab\sqrt2 = \frac{a}{b}2​=ba​ for some integers, let g=gcd⁡(a,b)g = \gcd(a, b)g=gcd(a,b) and set p=a/gp = a/gp=a/g, q=b/gq = b/gq=b/g. Same value, and now ppp, qqq have no common factor bigger than 1.

    The point of insisting on lowest terms: we're going to show ppp and qqq are both even. That's only a contradiction because we said in advance they share no factor.

  2. 2Clear the square root

    Then p2=2q2p^2 = 2q^2p2=2q2.

    Square both sides of 2=p/q\sqrt2 = p/q2​=p/q to get 2=p2/q22 = p^2/q^22=p2/q2, then multiply by q2q^2q2.

    More detail

    2=pq  ⟹  2=p2q2  ⟹  2q2=p2.\sqrt 2 = \frac pq \;\Longrightarrow\; 2 = \frac{p^2}{q^2} \;\Longrightarrow\; 2q^2 = p^2.2​=qp​⟹2=q2p2​⟹2q2=p2. Now everything is in integers — no square roots — which is where divisibility arguments work.

  3. 3p must be even

    p2p^2p2 is even, so ppp is even: p=2kp = 2kp=2k.

    p2=2q2p^2 = 2q^2p2=2q2 is a multiple of 2. If ppp were odd, p2p^2p2 would be odd. So ppp is even.

    More detail

    Odd numbers square to odd numbers: (2m+1)2=4m2+4m+1=2(2m2+2m)+1(2m+1)^2 = 4m^2 + 4m + 1 = 2(2m^2 + 2m) + 1(2m+1)2=4m2+4m+1=2(2m2+2m)+1.

    So "ppp odd ⇒ p2p^2p2 odd", whose contrapositive is "p2p^2p2 even ⇒ ppp even". Since p2=2q2p^2 = 2q^2p2=2q2 is visibly even, p=2kp = 2kp=2k for some integer kkk.

  4. 4Then q must be even too

    Substituting, q2=2k2q^2 = 2k^2q2=2k2, so qqq is even.

    (2k)2=2q2(2k)^2 = 2q^2(2k)2=2q2 gives 4k2=2q24k^2 = 2q^24k2=2q2, i.e. q2=2k2q^2 = 2k^2q2=2k2. The same argument as before shows qqq is even.

    More detail

    p=2k  ⇒  p2=4k2=2q2  ⇒  q2=2k2.p = 2k \;\Rightarrow\; p^2 = 4k^2 = 2q^2 \;\Rightarrow\; q^2 = 2k^2.p=2k⇒p2=4k2=2q2⇒q2=2k2. This has exactly the shape of p2=2q2p^2 = 2q^2p2=2q2 with the roles changed, so the previous step applies verbatim: q2q^2q2 is even, hence qqq is even.

  5. 5Contradiction

    ppp and qqq are both divisible by 2, contradicting gcd⁡(p,q)=1\gcd(p,q) = 1gcd(p,q)=1. So 2\sqrt22​ is irrational.

    We assumed no common factor, and derived the common factor 2. The assumption that 2\sqrt22​ is rational must be false.

    More detail

    Recap of the logic: (rational) ⇒ (lowest-terms fraction exists) ⇒ (both parts even) ⇒ (not lowest terms). A statement implying its own negation is false.

    The picture above is a second proof. Take the solution with ppp smallest. Since 1<pq<21 \lt \frac pq \lt 21<qp​<2, both 2q−p2q - p2q−p and p−qp - qp−q are positive and 2q−p<p2q - p \lt p2q−p<p. That's a solution with a smaller first number, a contradiction. This is infinite descent, the method Fermat later uses for x4+y4=z2x^4 + y^4 = z^2x4+y4=z2.

    Generalisation: the same proof shows n\sqrt nn​ is irrational whenever nnn is not a perfect square — replace "even" with "divisible by a prime ℓ\ellℓ that appears an odd number of times in nnn".

Takeaway. Pattern: assume a rational in lowest terms, push a divisibility fact through an equation, and show it lands on both numerator and denominator.

Used by Fermat for n=4n = 4n=4: no solutions to x4+y4=z4x^4 + y^4 = z^4x4+y4=z4.
