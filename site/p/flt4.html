On the way to Fermat's Last Theorem, The Langlands program

Fermat for n=4n = 4n=4: no solutions to x4+y4=z4x^4 + y^4 = z^4x4+y4=z4

Pierre de Fermat, c. 1640: infinite descent, his only surviving proof
Theorem

There are no positive integers with x4+y4=z2x^4 + y^4 = z^2x4+y4=z2. In particular x4+y4=z4x^4 + y^4 = z^4x4+y4=z4 has none, and Fermat's Last Theorem reduces to odd prime exponents.

Fermat wrote in a margin that xn+yn=znx^n + y^n = z^nxn+yn=zn has no solutions for n≥3n \ge 3n≥3 and that the margin was too small for his proof. For n=4n = 4n=4 he did leave a proof, and it is a gem: assume a smallest solution and build a smaller one. It also cuts the full problem down to odd primes, which is where Wiles picked it up 350 years later.

  1. 1Prove something stronger

    Suppose x4+y4=z2x^4 + y^4 = z^2x4+y4=z2 has a positive solution, and take one with zzz as small as possible.

    A solution of x4+y4=z4x^4 + y^4 = z^4x4+y4=z4 gives one of x4+y4=(z2)2x^4 + y^4 = (z^2)^2x4+y4=(z2)2, so ruling out squares on the right is stronger. Well-ordering lets us pick a minimal zzz; we'll build a solution with smaller zzz.

    More detail

    Proving more can be easier: the weaker hypothesis "the right side is a square" is exactly what survives the descent, while "the right side is a fourth power" would not.

    The set of values zzz over all positive solutions is a non-empty set of positive integers (if any solution exists), so it has a least element: this is well-ordering, the principle behind "minimal counterexample" arguments.

  6. 6Only odd primes are left

    If xp+yp=zpx^p + y^p = z^pxp+yp=zp has no positive solutions for every odd prime ppp, then Fermat's Last Theorem holds for all n≥3n \ge 3n≥3.

Exponent 4 is impossible by this proof. So the whole theorem comes down to odd primes ppp: Euler handled p=3p = 3p=3, Dirichlet and Legendre p=5p = 5p=5, Lamé p=7p = 7p=7, Kummer all "regular" primes, and Wiles all of them.

Takeaway. Infinite descent: from any solution build a strictly smaller one. Combined with "minimal counterexample", it proves non-existence.
